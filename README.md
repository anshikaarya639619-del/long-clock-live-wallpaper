# Long Clock Live Wallpaper

A native Android live wallpaper that draws a large digital clock, date, and an optional user-selected photo. The clock refreshes every second while the wallpaper is visible.

## Build APK for free
Every push to `main` runs GitHub Actions. Open the repository's **Actions** tab, open the latest **Build Android APK** run, and download the artifact named `long-clock-live-wallpaper-debug-apk`.

## Install
1. Download and extract the artifact ZIP.
2. Install `app-debug.apk` on your Android phone (allow install from this source if Android asks).
3. Open **Long Clock Wallpaper** and select your photo.
4. Tap **Set live wallpaper**, then choose Lock screen if your Android phone offers that option.

## Notes
- This is a native Android live wallpaper, not a static PNG.
- Android/OEM behavior differs. Some phones only allow live wallpapers on the Home screen; lock-screen support is device-dependent.
- This is a debug APK for testing, not a Play Store release.
