# DepthPix Pro — original Android wallpaper studio

Offline-first Android wallpaper studio. This is an original implementation and does not copy proprietary DepthPix code, artwork, or branding.

## Current build features
- **1000 generated wallpaper designs** available offline. They are procedural combinations of 10 palettes, 10 visual pattern families, and 10 seeded variations; they are not 1000 downloaded photographic assets.
- Previous / next / random wallpaper browsing.
- Touch-driven 2.5D parallax preview and adjustable depth intensity.
- Custom photo import.
- Large stacked “long clock” or classic clock, adjustable size, four clock colors, date toggle, and custom text.
- Export a 2× PNG through Android's save dialog.
- Android Live Wallpaper service with home-screen scroll parallax and live clock refresh.
- No paid API, account, subscription, or API key.

## Important technical limits
- The 1000 designs are generated locally from code, not a curated library of 1000 real photographs.
- Photo depth is simulated with whole-image movement. Automatic AI subject cut-out, true foreground/background depth maps, and separate object layers are not implemented.
- The live wallpaper currently renders the generated design and clock. Imported personal photos are not yet persisted into the live wallpaper service.
- APK generated by Actions is a debug build, not Play Store-signed.

## Build
GitHub Actions workflow: **Build DepthPix Pro APK**. Open Actions, select the latest successful run, then download artifact `depthpix-pro-debug-apk`.
